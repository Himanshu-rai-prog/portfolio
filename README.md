# Himanshu Rai — Portfolio

Built from `Portfolio_Build_Materials_Week4.pdf`: one-line claim, content map (Home / About / Projects / Skills / Experience / Contact), identity kit (clean, modern, minimal), the five case studies, and the "real screenshots over AI-generated visuals" image direction.

## Files
- `index.html` — all page content
- `style.css` — all styling (tokens at the top of the file)
- `script.js` — mobile nav toggle + footer year

## What still needs your input
Every `[bracketed]` line in `index.html` is a placeholder — search for `[Add` to find them all. They cover:
- Home: short introduction
- About: profile paragraph, education, interests, direction, real photo
- Projects: problem / approach / technology / result for each of the 5 case studies, plus real screenshots
- Experience: CodeAlpha internship description and dates, E-commerce App context
- Contact: email, LinkedIn, GitHub links

Each project and the About section has a dashed placeholder box — replace it with a real `<img>` once you have the screenshot/photo, e.g.:
```html
<img src="images/fake-news-detection.png" alt="Fake News Detection app screenshot">
```
Put image files in a new `images/` folder alongside `index.html`.

## Deploying to your existing GitHub Pages repo
1. Copy `index.html`, `style.css`, and `script.js` into your GitHub Pages repo, replacing the current placeholder page.
2. Add an `images/` folder with your real screenshots and profile photo.
3. Commit and push — GitHub Pages will redeploy automatically at your existing URL.
